# Offline interface fonts

The existing Cairo and Noto Naskh Arabic fonts cover every character in the
Arabic, English and Spanish application localization files. The catalogue also
displays the native Bengali language name, whose characters were not covered.
Noto Sans Bengali is now bundled as an interface fallback; no Quran text/font
resource or source archive is modified.

Source: [Google Fonts Noto Sans Bengali](https://github.com/google/fonts/tree/main/ofl/notosansbengali).
