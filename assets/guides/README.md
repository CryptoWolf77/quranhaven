# Local usage demonstrations

These twelve GIFs and twelve PNG posters are real Quran Haven browser captures,
recorded on 2026-10-12 in Arabic, English and Spanish. The captured build uses the
production read-only text service; Quran text and fonts were not generated,
rewritten or substituted. The local browser's offline mode was enabled before
the final offline-reader capture in each language.

Each language has four short demonstrations: reader navigation/search,
Tafsir/translations/recitations, Khatmah/memorization plans, and browser offline
preparation. Identical successive frames may be coalesced by the GIF encoder.
Posters are shown by default; playback is explicit, local and optional. Written
instructions remain available with reduced motion or unavailable media.

The screenshots demonstrate desktop web controls, not every phone layout.
The guide separately explains native-only audio downloads and reminders, and
does not promise cloud sync, browser offline audio or local export/import.
